# 模型、均衡条件与数值求解范围

本文件先给出要解决的问题、冻结的经济模型和求解方程，再说明实现与验证边界。
这是一份新数值实现，不是对 v1.1.1 历史结果的追认，也不读取 v1.2 候选。

## 1. 问题是什么

我们不是在已知需求函数上选择两个价格，而是在策略行为内生决定成交概率时选价。
原流程中的五类风险必须分开：

1. 正温度 logit 或小步长停止，不等于原博弈的最优反应。
2. 对罕见继续事件，没有抽到样本不等于事件不可达。错误的条件中单概率会改变
   旧司机留存，以及期初提前出现/隐藏等待的收益。
3. 评估当前策略时，不能把它的实际留存替换成最优留存；否则会漏算完整策略偏离收益。
4. 在粗筛时删除尚未收敛的菜单，随后对剩余菜单取最大值，不是完整价格优化。
5. 类型离散误差、路线分布估计误差、均衡误差、价格网格误差和报告样本误差不同。
   测试通过、文件名包含 precision、一次审计通过，都不能将它们自动消除。

这里要求输出的对象是每个厚度 m 的 (p1,p2,p_flat,V)，同时输出这些数值的证据等级。
不将 p1 < p_flat < p2 或 V 的单峰形状作为可行性约束。

## 2. 冻结的基本模型与随机顺路度

`rescue_solver/core.py` 实现 v1.1.1 的经济规则；不包含旧外层优化器或策略缓存。
来源及抽取范围见 `PROVENANCE.md`。运行时记录所有求解模块的 SHA-256。

单个乘客的路线归一化为 [0,1]，私人价值 v ~ U[0,1]。潜在司机来自同一个固定池，
N ~ Poisson(m)，不是每一期重新生成一批外生司机。每位司机的私人成本 c ~ U[0,1]，
独立于路线。司机只知道自己的类型，不知道实际 N、其他司机类型或乘客 v。

随机生成司机起点 O、路线长度 L、同向指标 B：

\[
O\sim U[-.75,.75],\quad L\sim U[.45,1.75],\quad B\sim\mathrm{Bernoulli}(.82).
\]

顺路度为

\[
d(O,L)=\max\{0,\min(1,O+L)-\max(0,O)\},\qquad
s=B\frac{2d(O,L)}{1+L}\in[0,1].
\]

反向路线在当前设定下直接记 s=0；不是对反向行驶计算正向共线重叠。
司机有效成本和乘客顺路惩罚为

\[
a(c,s)=c+\kappa(1-s),\qquad v-\ell(1-s).
\]

参数沿用 beta=.96、delta=.90、ell=.35、kappa=.18、omega_old=.004、
omega_hidden=.005、p_bar=1。这里旧司机第二期利润是 **delta*p1-a**，
不是 delta*(p1-a)。这两种模型不混用。

求解时将随机 OD 样本构造为带权 s 支撑（零点原子加正值分位箱）；c 用区间均值。
实际模拟中，每个市场的 N、各司机的成本类型/顺路类型、混合行动和乘客 v 都随机抽取。
因此不是把顺路度固定成一个常数，但仍然是连续分布的有限类型近似。

`--route-seed` 控制 OD 样本；不填则生成并保存一个新的随机种子。
`--seed` 独立控制求解/市场随机数。同一实验内所有菜单共用一个路线分布支撑，
避免用“碰巧抽到更好路线”选出菜单；要检验分布估计误差，应换 route seed 完整重算。
固定两个种子可复现；随机不等于不可复现。

注意：原经济配置文件中的 `solvers` 是旧算法的预算，不会被伪装成新算法的精度。
新算法实际预算在每次 `request.json/settings` 中完整记录，由命令行控制。

## 3. 时序、可见信息与支付

1. 平台承诺 0 <= p1 <= p2 <= p_bar。
2. 每位司机观察 (c,s)，在早进入 E、隐藏等待 H、退出 O 中选择。
3. 乘客观察早进入司机的顺路度多重集，比较立即接受、继续且选择 q∈{p1,p2}、退出。
   q 在隐藏司机出现之前决定。
4. 已早进入的司机只观察自身早进入经历、请求仍继续及 q，根据这个信息集选择留存。
   本实现没有让司机观察其他早进入司机的数量/顺路度。
   隐藏司机在 q >= a 时可以出现，第二期没有额外邀请成本。
5. 乘客观察第二期可用选项，选择净效用最大的司机或退出。

司机收益：立即中单 p1-a；旧司机留存时付 omega_old，中单另得 delta*p1-a；
选择 H 在期初付 omega_hidden，若以后中单另得 q-a。未中单留存仍付留存成本，
H 即使从未激活也付隐藏等待成本。退出收益零。

乘客第一期净效用 v-ell*(1-s)-p1；第二期旧司机净效用
beta*[v-ell*(1-s)]-p1，新司机为 beta*[v-ell*(1-s)]-q。
不将旧司机的支付提高为 p2。

正效用的行动并列：先立即接受，再低价继续；零效用并列退出。
同一期同等最优司机均匀分配。这些约定是模型的一部分。

## 4. 有限类型内层：Bayes + 最优反应 + 互补条件

对类型 (c_i,s_j)，未知量为 e_ij、h_ij、o_ij，以及每个 q 的留存概率 r_qij。
满足 e+h+o=1 和所有概率非负。类型权重为 f_i g_j。

### 4.1 由策略生成可见与隐藏司机分布

\[
\lambda^E_j=m g_j\sum_i f_i e_{ij},\qquad
\lambda^H_j(q)=m g_j\sum_i f_i h_{ij}\mathbf1\{q\ge a_{ij}\}.
\]

对于早出现的顺路类型 j，乘客的聚合留存概率为

\[
\rho_j(q)=\frac{\sum_i f_i e_{ij}r_{qij}}{\sum_i f_i e_{ij}},
\]

只在分母为正时由 Bayes 确定。零概率早出现类型属于离轨信息，不可将它默认称为
已认证的贝叶斯后验。原引擎对小于阈值的分母使用零占位；新结果始终不宣称完整 WPBE。

在 tagged-driver 偏离计算中，其他司机按原 Poisson 池的 Palm 分布抽取，
并在该司机选择 E 时额外加入它自己的顺路类型。不能把本人混进竞争者数量。
这里明确采用匿名 Poisson 博弈的 tagged-agent 约定：乘客视角总数为 Poisson(m)，
单列一个参与司机时，其余司机仍按 Poisson(m) 处理；这不是将 N 条件在 N>=1 后
简单减去 1。若改用后一种司机先验，应另写模型和重算。

### 4.2 乘客最优行为

设 n 是观察到的早司机顺路类型计数，s_max(n) 是最高顺路度。定义

\[
I(v,n)=\max\{v-\ell(1-s_{\max})-p_1,0\},
\]

没有早司机时 I=0。对继续价格 q，

\[
C_q(v,n)=E\left[\max\left\{0,
\max_{i\in\mathrm{old}}\{\beta[v-\ell(1-s_i)]-p_1\},
\max_{i\in\mathrm{new}}\{\beta[v-\ell(1-s_i)]-q\}\right\}\mid n,q\right].
\]

比较 I、C_p1、C_p2、0，按上述并列规则行动。没有额外进入成本，因此进入/不进入
在本实现中由是否有正的最优效用表达，不另造一个固定进入率。

固定 n 时 C_q 是 v 的分段线性函数。代码枚举所有效用折点和成对交点，精确积分
各行动所占的 v 区间（浮点精度意义）；第二期被接受的阈值也纳入分段。

更具体地，令 g^O_j=p1+beta*ell*(1-s_j)、g^N_j=q+beta*ell*(1-s_j)，Z 是
第二期可用司机的最小广义成本，无司机时 Z=+infinity。则

\[
\Pr(Z>z\mid n,q)=
\prod_j[1-\rho_j(q)\mathbf1\{g^O_j\le z\}]^{n_j}
\exp\{-\sum_j\lambda^H_j(q)\mathbf1\{g^N_j\le z\}\}.
\]

因此 C_q(v,n)=E[(beta*v-Z)_+|n,q]，可以直接由该有限阶梯 CDF 积分。

### 4.3 司机条件收益

令 d_j(q) 是 tagged 早司机观察到继续且价格 q 的概率，b_j(q) 是该事件且在本人
留存时中单的联合概率；那么正概率信息集的条件中单概率为

\[
\pi^E_j(q)=b_j(q)/d_j(q),\qquad
D_q(c_i,s_j)=\pi^E_j(q)(\delta p_1-a_{ij})-\omega_{\rm old}.
\]

不能把 Pr(中单且继续) 当 Pr(中单|继续)，也不能将样本分母零等同于数学分母零。
设 A_j 为早进入后立即中单概率，B^H_j(q) 为隐藏司机在激活 q 后中单的无条件概率。
早进入后采用最优留存的收益与当前策略收益分别为

\[
U_E^{BR}=A_j(p_1-a_{ij})+\sum_q d_j(q)\max\{D_q,0\},
\]
\[
U_E^\sigma=A_j(p_1-a_{ij})+\sum_q d_j(q)r_{qij}D_q.
\]

隐藏等待收益

\[
U_H=-\omega_{\rm hidden}+\sum_q B^H_j(q)\max\{q-a_{ij},0\},\qquad U_O=0.
\]

令 W_ij=max(U_E^BR,U_H,0)。序贯理性要求

\[
0\le e_{ij}\perp W_{ij}-U_E^{BR}\ge0,\quad
0\le h_{ij}\perp W_{ij}-U_H\ge0,\quad
0\le o_{ij}\perp W_{ij}\ge0.
\]

后续留存要求 r=1 当 D>0、r=0 当 D<0，D=0 时可以混合。
这里的初始互补关系必须与后续留存条件一起检查；单独使用 U_E^BR 会掩盖错误留存。
完整策略偏离收益为

\[
R_{ij}^{\rm full}=W_{ij}-[e_{ij}U_E^\sigma+h_{ij}U_H].
\]

条件留存 regret 为 max(D,0)-rD。新求解器同时报告这两个最大值、互补残差和支持差距。
ε 门槛是效用单位，不是成交百分点，也不是迭代步长。
默认最大 regret 门槛为 0.00075；行动概率超过 0.001 的支持上，收益差距门槛为
0.0015。训练停止与独立审计都同时检查两类门槛；不允许小概率权重掩盖明显劣势行动。
这是显式的数值支持约定，并不是对所有严格正概率行动的精确互补证明。

### 4.4 未观测、罕见和离轨信息集

小模型可枚举总竞争司机数 <= K 的所有向量，不对已枚举概率重新归一化。
遗漏总概率记为 τ。当已枚举事件质量为 d，中单联合质量为 b 时，条件中单概率界为

\[
\frac{b}{d+\tau}\le\pi\le\frac{b+\tau}{d+\tau}.
\]

d=0 且 τ>0 时保留 [0,1]。d=τ=0 时 Bayes 不适用，须指定离轨信念；当前保留
[0,1]，不把它自动补成通过。训练用 .5 占位只服务迭代，并明确不构成均衡信念。
审计使用整个区间，不能靠这个占位值获得通过。

正式 WPBE 的 assessment 是 (sigma,mu)：sigma 包括全部司机和乘客行为策略，mu
包括每个信息集的信念。每个信息集都要求序贯最优；每个正概率信息集要求
mu(B|h)=Pr_sigma(B∩h)/Pr_sigma(h)。零概率信息集不受这一比率直接确定，
但信念必须支持在该信息集允许的状态上，并与指定后续策略的最优性一并验证。
只返回 sigma 或把分母零替换为任意数值，均不是完整 assessment。

大模型随机抽取竞争司机计数，对每个计数精确积分 v；独立审计在固定的返回策略上
对有界事件/中单率使用同时 Hoeffding 界，再传播到条件中单率与 regret 上界。
这个分布无关界保守，稀有信息集可能需要极大样本，因此 `insufficient_evidence`
是实质结果，不是运行失败。禁止降低审计门槛以获得漂亮曲线。

这些界只覆盖计数采样/截断误差，不覆盖浮点、10 节点并列积分或类型离散误差。

## 5. 外层问题与均衡选择

记 E(p1,p2;m) 为相应对称 WPBE 的集合，χ 是预先声明的、跨菜单一致的均衡选择规则。
理论对象是

\[
M_\chi(p_1,p_2;m)=E_{\chi(E(p_1,p_2;m))}[\mathbf1\{\text{最终成交}\}],
\]
\[
M_R^*(m)=\max_{0\le p_1\le p_2\le1}M_\chi(p_1,p_2;m),\quad
M_F^*(m)=\max_{0\le p\le1}M_\chi(p,p;m),\quad V(m)=M_R^*(m)-M_F^*(m).
\]

χ 不是“每个菜单取平台收益最高的均衡”。当前数值分支规则是同一冷启动模式、
同一温度表和种子规则，不能证明唯一性或抽象 χ 的连续性；更换 early/hidden 初值
是单独的分支敏感性实验，不在其间按平台完成率择优。

完整问题是带互补约束的非凸双层随机优化问题（MPEC 表述），不是现成的 LP/MIP。
固定离散状态与活跃集能形成局部子问题，但对一个活跃集求得局部解不等于全局均衡。
本实现没有声称使用通用 MIP 求解器解决它，也没有虚构 MIP gap。

实现为预先指定的完整三角价格网格：每个菜单冷启动并独立审计，所有记录保留。
flat 在所有对角菜单上单独最大化；对角使用与 rescue 完全相同的策略，保证机制嵌套。
flat 仍是同一个两期博弈，只撤去价格差；不是强制全体司机第一期出现，也不是
额外拿一个不同的一期静态模型充当基准。
选择样本用于锁定两个价格，另一份独立报告样本用于估计差值，不按报告结果 fallback。
如果任何未决菜单仍可能改写最优值，只输出未认证的原始领先候选。
即便所有菜单通过，选择样本也可能无法区分接近的价格；报告同时给出固定策略
完成率的全菜单 Hoeffding 区间和保守有限网格取值误差界，不将原始样本领先等同精确最优。

即使每个菜单通过数值检查，有限网格最大值也不是连续价格全局最大值。
当前版本不含有连续价格误差上界的自适应区间分支定界，也没有证明网格邻域闭合。
加密 --step 需要完整重算或同身份分阶段扩展，不能仅凭局部邻点判断全域最优。

在一致选择规则和完整最优化下，rescue 含 flat 的对角子集，因此理论 V>=0。
独立有限样本报告出现负差值时保留原值与误差，不能截断为零。
p1<=p_flat<=p2 和 V 单峰均不由这条嵌套性质推出。
若最大值存在性尚未证明，理论定义应以 supremum 代替 max；argmax 价格的存在性
是单独的问题。有限价格网格上的最大值则总能取得（前提是各菜单均衡已经求解）。


## 6. 实现与理论对象的距离

运行方法见仓库根目录 README。内层使用阻尼最优反应与温度延拓，最后必须进入零温度阶段；没有声称通用 MIP 求解器能认证这个非凸均衡问题。保守后验区间可能阻止候选通过，这是证据不足，不应放宽门槛。

完整研究结果仍需类型支撑加密、独立路线种子、并列积分精度、罕见计数条件抽样、离轨信念构造、多初值分支比较和连续价格误差控制。当前包不声称已经完成这些证明；任何输出的 `wpbe_certified` 都为 false。
