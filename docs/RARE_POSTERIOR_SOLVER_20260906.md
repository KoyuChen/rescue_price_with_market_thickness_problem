# 稀有历史后验接入求解与审计

新增独立求解版本，将完整 Poisson 尾部后验界用于留存策略更新和独立审计。
原来 m=6、12、24 的极罕见在轨历史不能由普通样本稳定观察，旧版会冻结其
留存策略。这使训练 regret 接近零仍不足以认定均衡通过。

## 接入方式

- `rare_posterior_evaluator.py` 在每次更新后按当前策略重新计算信念，缓存只复用
  完全相同的早期强度、各继续价格的留存率、新司机强度和价格。
- 先尝试覆盖全部计数的结构排除；未排除的稀有历史使用确定性条件计数枚举。
  只有分母下界严格为正、整个中选概率区间导致的留存收益误差不超过 1e-9，
  才用于训练。同步更新条件留存收益和第一期最优留存计划的联合收益。
- 独立审计用后验区间两端给出留存 regret 和支持集误差的最坏情形上界。
  第一阶段完整偏离计划仍使用独立计数样本的联合 Bernstein 界；普通继续历史
  保留原条件计数审计，alpha 各占一半。
- 枚举保留任意严格为正的留存率，包括极小正数。仅当路线计数强度严格为零时，
  该路线的竞争计数才可确定为零。枚举外 Poisson 尾部进入分子和分母的界。
- 枚举预算最多 8 个显式计数维度、100000 个状态；预算不足或后验区间不够窄时
  保留未决标记，不因运行时间或样本中未出现该历史而宣告通过。

`bounded_rare_posterior.py` 和 `strict_multi_route_envelope.py` 是独立辅助版本。
修正了低计数上限低于 Poisson 均值时的尾部界、竞争路线计数为零时的立即成交
基准，并要求有限矩形内高价选择区间严格为零。1e-14 的正区间也不会被排除。

所有界仍受既有双精度运算与 64 节点并列分配积分限制，不是精确算术或连续类型
WPBE 证书。此次接入没有降低 regret 0.00075、支持集误差 0.0015 的门槛。

## 验证

本次发布所含的 100 项测试通过（原 90 项加本次 10 项）。新增测试覆盖：

1. 正负留存利润下的概率区间端点最坏情形界；
2. 压缩联合测度与直接全路线枚举的一致性及未枚举尾部；
3. 正历史不能变成离轨信念，收益和概率随修复同步更新；
4. 严格正短区间不被排除，零竞争计数不制造更好的即时司机；
5. flat 审计与既有求解器一致；信念缓存失效；策略更新中断后精确恢复与哈希拒绝。

`check_rare_posterior_integration.py` 读取先前已归档的真实冻结策略，进行 1000
计数样本的接入回归检查。这不是最终百万样本验收：它的目的恰好是检出旧策略
已经被后验界揭示的留存偏差。输出保留完整 posterior records 和审计界。

三组真实冻结策略的回归均完成，未决训练历史都归零；新版检出的留存 regret 为：

| m | 旧策略的留存 regret | 是否超过原 0.00075 门槛 |
|---:|---:|---|
| 6 | 0.0138182611 | 是 |
| 12 | 0.0033705712 | 是 |
| 24 | 0.0015838543 | 是 |

三项旧策略均被新审计正确拒绝。这验证了修复会改变留存激励；不是说修复后的
新均衡已通过审计。1000 样本回归的普通历史界仍很宽，完整结果仅供接入检查。
见 [回归记录](../results/rare_posterior_integration_20260906/summary.json)。

## 独立冷启动

新版 m=6、12、24 已实际启动，并完成首轮策略更新及检查点写入。
运行观察见 [运行快照](../results/rare_posterior_integration_20260906/active_runs.json)。

`run_rare_posterior_markets.py` 对 m=6、12、24 启动相同完整支撑的 homotopy
冷启动，使用全新种子。原 m=1、3、48 及旧版对照记录可继续保留。
每菜单仍用 2048×48 支撑、50000 训练计数、两组各 1000000 独立审计；
同伦阶段为 (.02,40)、(.004,60)、(.0005,100)、(0,500)，各次更新原子保存。

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -u run_rare_posterior_markets.py --source-run runs/thick_checkpointed_20260905 --output runs/thick_rare_solver_20260906 --m 6 12 24 --workers 3
```

同一命令恢复时验证输入、源码及策略哈希。通过 rescue/flat 验证门槛的厚度自动
进入原全域价格网格、局部加密及最终独立配对比较。失败候选保留，尚未完成
的求解不得声明外层最优价格、V*(m) 或中间峰值已经确认。
