## 外层价格搜索

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -u run_accelerated_m3_search.py \
  --gate-root results/m3_reactivated_20260906 \
  --model-request results/research_gate_20260905/request.json \
  --output runs/m3_outer_search
```

新评价耗时 2.6216 秒，约 1.34 倍；所比较收益和概率的最大差为 5.6e-17。
