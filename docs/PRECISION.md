# 当前精度：哪些预算不能被叫作 research precision

当前代码可以生成候选策略、完成指定价格网格并诊断错误，但不是实用的高精度 WPBE
认证器。除了离轨信念和类型误差，当前保守审计界本身也存在严重的样本效率瓶颈。

## 1. 五层精度不可混用

| 层次 | 当前处理 | 尚不能保证的事 |
|---|---|---|
| 价值积分 | 对分段仿射乘客收益切分区间 | 浮点/并列积分的严格总误差界 |
| 内层策略 | 最大完整策略/留存 regret 0.00075；支持差距 0.0015 | 预算内收敛、所有罕见信息集和完整信念系统 |
| 类型 | 默认 15 个成本点、至多 22 个顺路点；800000 个 OD 抽样 | 连续类型收敛和路线分布误差已消除 |
| 价格 | 指定全域三角网格，例如步长 0.1 或 0.05 | 最优价格误差就是半个步长、连续价格全局最优 |
| 成交报告 | 选价后独立的共同市场配对模拟 | 弥补错误均衡或遗漏价格候选 |

## 2. 当前统一概率界的硬限制

`solver.py` 使用

\[
r_n=\sqrt{\log(2K/\alpha)/(2n)},\qquad
K=S+Q+3QS,
\]

作为各事件/中单率的同时 Hoeffding 半径。采样模式的期初 regret 上界是样本 regret
加上 `2*r_n*(p_bar+Q*(p_bar+omega_old))`。
默认 `S=22,Q=2,alpha=.05,p_bar=1,omega_old=.004` 时：

| 每次独立审计计数样本 n | 仅该误差附加项 |
|---:|---:|
| 2000 | 0.28119146 |
| 10000 | 0.12575264 |
| 100000 | 0.03976648 |
| 1000000 | 0.01257526 |

这些数值已经大于 0.00075 的门槛。因此，对这种配置，README 中的常用探索预算
**不可能通过当前这条保守期初界**，不是“多跑几轮也许就会通过”。
即使样本 regret 恰为零，该附加项降至门槛也至少需要 281132935 个计数样本；
这仅是必要条件，不能解决条件后验、离轨信念、支持差距或类型误差。
不建议靠盲目堆到此样本量解决问题。

小模型的完整计数枚举走的是截断尾界，可在特定例子通过。通过这些玩具测试
不能说明上述大模型采样配置能通过。

## 3. 应优先修复的方向

需要将粗糙的统一率误差传播，改进为利用已知收益范围、相关性和方差的直接收益界；
对罕见信息集采用可验证的条件积分/分层或重要性采样，并明确处理真正的零概率信息集。
所有改进都必须保留独立审计、抽样权重和完整错误界，不能以点估计替代认证。
这些是后续工作，当前仓库没有声称已经实现。

在此之前，价格夹序或中间厚度峰值只应作为“未认证候选的探索现象”报告。
当前 grid 的 `wpbe_certified` 与 `V_is_certified_optimized_value` 均为 false。

## 4. 100 万报告市场意味着什么

单个完成率的 Bernoulli 标准误至多为 0.0005，即 0.05 个百分点；
rescue-flat 的配对差值取 -1、0、1，其标准误需要按实际配对差计算，不能套用
单个完成率的标准误。程序输出对应标准误和近似区间。

这些是固定候选策略的 Monte Carlo 误差，不包括训练策略误差、价格选择误差、
类型离散误差或均衡选择不唯一。小误差线也不能把一个未认证候选变成最优均衡。
