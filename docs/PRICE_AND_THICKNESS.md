# 价格关系与中间厚度峰值：可推导什么、需要计算什么

本页是在 `MODEL.md` 的固定经济规则下的推导，不是对任何旧数值表的认可。
价格优化以 supremum 表述；没有预先假设最优价格存在或均衡唯一。

## 1. 不能预先施加的价格关系

模型只限制 `0 <= p1 <= p2 <= p_bar`。独立优化的 flat 价格不必由此满足
`p1 <= p_flat <= p2`，三个价格也不必对厚度单调。把这些关系加入求解约束，
再用结果声称发现了它们，会形成循环论证。

因此程序逐点检查价格夹序、三条价格的相邻差分以及 `p2-p1`，保留所有反例。
目前没有证明上述价格夹序或价格单调性。
还应查看高价是否实际激活：如果高价分支几乎不发生，仅凭选出的 `p2` 不能断言
加价在起作用，也不能排除许多不同 `p2` 产生几乎相同完成率的情况。

## 2. 机制嵌套给出的非负性与薄端极限

在同一经济模型、同一均衡选择规则下，rescue 包含所有 `(p,p)` 菜单，所以

\[
0\le V(m)=M_R^*(m)-M_F^*(m)\le M_R^*(m)\le 1-e^{-m}.
\]

最后一个不等式因为一个市场至少有一名司机才能成交。因此

\[
\lim_{m\downarrow0}V(m)=0.
\]

这针对正确求解并完整优化的值；有限样本选价与独立报告值仍可能出现负差值。
程序不得把这样的差值截为零。

## 3. 本模型下的厚端极限：一个 flat 构造

下面讨论连续可选价格，不是把有限价格网格直接外推到无限厚度。
假设 `kappa>0`、`0<beta,delta<=1`、两个等待成本严格为正。
设成本下端为 `c_min`，顺路度上端为 `s_max`，且联合类型分布在这个最优角点的
每个邻域都有正概率。定义

\[
a_0=c_{\min}+\kappa(1-s_{\max}),\qquad
v_0=c_{\min}+(\kappa+\ell)(1-s_{\max}).
\]

考虑有成交可能的情形 `a0<p_bar` 且 `v0<1`。任选足够小的正数 ε，令 flat
价格 `p=a0+ε`，并使

\[
\varepsilon<\omega_{\rm hidden},\qquad
\delta\varepsilon<\omega_{\rm old},\qquad p\le\bar p.
\]

1. 隐藏司机即使必然中单，其总收益也不超过
   `p-a0-omega_hidden = ε-omega_hidden < 0`，故 H 严格劣于退出。
2. 旧司机留存即使必然中单，收益也不超过
   `max(delta*p-a0,0)-omega_old <= delta*ε-omega_old < 0`，故留存严格劣于离开。
3. 没有隐藏和留存，乘客只有立即成交或退出。所有 `a<p` 且有正成交可能的司机
   早进入有严格正期望收益；`a>p` 的司机不可早进入。这给出 flat 的纯策略结果。

记 `H(ε)=Pr(a<a0+ε)>0`。这些可成交司机的顺路度满足
`s > s_max-ε/kappa`，其立即成交所需价值不超过
`v0+(1+ell/kappa)ε`。因此

\[
M_F^*(m)\ \ge\
\big[1-v_0-(1+\ell/\kappa)\varepsilon\big]_+
\big[1-e^{-mH(\varepsilon)}\big].
\]

另一方面，任何菜单中，早司机成交支付至少覆盖 `a`，新司机出现也要求 `q>=a`。
第二期的乘客折扣 `beta<=1` 不会降低成交所需的原始价值。所以任何成交都要求
`v>=a+ell(1-s)>=v0`，给出

\[
M_R^*(m)\le1-v_0.
\]

固定 ε 令 m 趋于无穷，再令 ε 趋于零，与机制嵌套结合得到

\[
\lim_{m\to\infty}M_F^*(m)=
\lim_{m\to\infty}M_R^*(m)=1-v_0,
\qquad \lim_{m\to\infty}V(m)=0.
\]

原连续 OD/成本模型的 `c_min=0,s_max=1`，故两个最优完成率趋于 1。
固定有限类型支撑一般 `c_min>0,s_max<1`，两者趋于该支撑自己的上界 `1-v0`，
仍可有增益趋零。不能把有限类型的完成率上限与连续类型的上限混为一谈。
上述 flat 构造中的 H 和留存为严格劣势行动，结论不靠从多个 flat 均衡中挑高收益分支。

## 4. 这仍然不是 single-peakedness 证明

两端增益趋零，只说明：若某个内部厚度有严格正增益，正增益不会只在无穷厚端出现。
若再有适当连续性/最大值存在条件，可以谈有限内部的最大点。
这不排除多个局部峰，也不证明峰在 6、12 或 24，更不能证明价格夹序。

实际网格应区分：

- 某个中间点的增益是否高于两个端点；
- 最大点是否能与其他中间点区分；
- 所有相邻差分是否先非负、后非正；
- 加密厚度、价格、类型和更换路线种子后是否稳定；
- 输入值的均衡与价格优化是否有足够证据。

`thickness_diagnostic` 与 `shape_diagnostic` 对前几项作描述/Monte Carlo 检查。
独立报告区间不包含均衡、价格网格和类型离散误差，故不能单独完成最后两项。
